Vapi Calendar Tool Installer

Creates the GHL availability and booking tools in a client's Vapi account, attaches them to the agents you pick, and writes the matching prompt section. Keys are sent only from this browser to Vapi and GHL. Nothing is stored.

01Vapi account

In Vapi, open the organization menu, then API Keys. Use the private key, not the public one.

02GHL sub-account

Settings, Private Integrations. Needs calendars, calendar events, contacts and locations (read) scopes.

Settings, Business Profile, or the ID in the sub-account's URL.

Filled from the sub-account when possible. Check it matches the calendar.

Appointments are titled "Caller Name X Business name".

03Tools to create

Untick a tool to skip it. The agent calls tools by these names. Letters, numbers, _ and - only.

04Attach to agents

Optional. Older copies of these tools on the selected agents are swapped for the new ones.

Connect Vapi in step 01 to list agents.

05Create

Progress

  1. Fill in steps 01 to 04, then create.
